# 功能与边界

本文说明 0.5.6 候选源码的已有能力。功能存在、自动化测试通过和真实项目内容准确是不同结论；当前执行状态见 [验证记录](validation.md)。

## 文件与来源

主文件可选择多份，每份生成独立报告；本次所选附件应用于所有主文件。附件不同的项目应分批处理。

| 格式 | 来源定位与读取范围 | 需要人工核对的部分 |
| --- | --- | --- |
| PDF | 尽量保留真实页码与原页；机器文字、扫描页和混合内容分别处理 | 复杂表格、跨页关系、叠印、图纸、读取不清和缺失附件 |
| DOC / DOCX | 按实际文件内容识别格式，按章节、段落和表格定位 | 不虚构 Word 页码；图片、复杂表格、文本框和内嵌附件可能有缺口 |
| XLSX / XLS | 按工作表、真实行号和单元格保留出处；上限 20 MB | 只读已有公式缓存，不执行宏、外部链接或自动计算缺失值 |
| 图片 / 扫描页 | 内置中英文 OCR，保留识别来源与待核验提示 | OCR 文本必须与原图核对，不能将识别文本等同于原件 |
| TXT | 保留段落和章节 | 无可靠页码时保持未知 |

没有可分析正文时明确失败；文件列出了附件目录不表示附件已经读取。删除一份报告只移除该报告记录，不删除原件。原始材料及业务数据不属于公开源码内容。

## 分析和人工核验

14 类分析包括：营业执照与经营范围、资质要求、评分细则、废标点、付款方式、评审方式、现场勘查、样品要求、业绩要求、人员要求、投标保证金、节能环保与强制采购、前后一致性、必须承诺。

四项固定输出为：废标项清单、必须加分项、必须承诺内容、投标可行性结论。“必须加分项”用于准备评分材料，不表示该项必得分或属于资格要求。

条款保留原文、出处、条件、例外、主体和阶段。未识别不代表不存在；机器引用校验通过也不能证明解读正确。缺资料、规则范围不明和未核验事项保持待核验，不能从空集合推出企业满足资格。

资格与符合性硬门槛独立判断，分值不能抵消已确认的不符合。技术、清单或报价满分情景与人工参考估分是内部测算，不能保证评审得分；商务及独立附加合计 95% 仅是内部筛选提示，不单独否决投标。多采购包、版本或评分范围不清时不跨范围合计。

同段独立评分和明确比值公式可逐项识别，但不能从总分声明补造缺项。独立封顶、共同封顶与分档标准分开处理；“本项”指向不清的连续固定认证分保留范围澄清和待核验。跨章业绩重述只有同范围且类型能对应时才合并来源，不把金额、日期或证明条件丢掉。合成样例校验通过不保证任意新评分表都能完整提取。

## 企业、政策与导出

本地企业资料库可管理执照、资质、人员、业绩和产品证据。自动字段录入与真实性、有效状态核验分开；冲突保留原值、新值与出处。报告保存生成时的企业与政策快照，旧报告不会因企业资料变化自动变成新结论。

产品政策匹配区分强制采购、优先采购及适用的绿色建材要求。型号、制造商、证明材料或适用范围不足时保持待核验。政策包可离线使用；主动检查官方依据只提示变化，不自动把变化应用到已保存报告，也不发送招标或证照内容。具体项目仍须核对有效文件、适用范围和正式澄清。

源码只保留政策事实目录及原件来源，不附官方 PDF/DOCX/网页或核对图。维护者可按 [政策目录说明](../assets/policies/README.md) 显式获取并核验缓存；应用启动不执行该下载。完整指标须打开官方链接或已核验原件查看。

PDF / Word 默认导出项目总览、评分表、四项输出、14 类详细内容和出处，同时保留核验状态与缺口。完整核查版可附原始条款和 AI 原答复。导出完整不表示内容已通过人工验收。

## 可选联网分析

默认开关关闭。配置模型或密钥不会立即发送招标材料；用户选择联网分析并开始本次任务后，才发送所选主文件、附件及企业材料的文字内容。连接测试只发送简短测试语句。接口地址、模型、服务额度和密钥由用户提供。

返回的 AI 候选独立保存，未确认前不接管主评分、资格硬门槛或已复核结论。引文按本次原文核对，未校验内容保持待复核。失败或取消保留已完成的离线初稿与已取得的部分内容，并显示未完成状态。容量不足时不以章节计数代替全文核验。

桌面 API 密钥使用系统安全存储（Windows DPAPI、macOS 钥匙串）；更换服务商或域名后需重新输入。浏览器开发版密钥仅在本次本地服务进程内保存，重启后需重填。

### 网页 AI 实验

Electron 桌面版提供豆包和 DeepSeek 内置网页入口，浏览器开发版不能完成该嵌入流程。用户自行登录，确认本次材料清单并点击开始后，程序尝试正常网页上传、提交、等待和取回；只打开登录窗口不发送材料。

这不是服务商官方集成。平台控件、登录、验证码、额度和环境限制会变化；遇到阻断时停止，不绕过保护，不自动购买或悄悄切换 API。网页实验会向平台上传所选原件和可读原文，须先确认材料可发送。

既有说明记载过豆包流程试验，也记载过 DeepSeek“使用环境异常”的限制；这些不能作为本候选当前真实平台可用的证明。两平台在本候选的真实账号流程均须单独复测。模式、回答结构齐全和成功保存也不能证明语义无漏误。

## 适用范围

离线规则不是本地大语言模型，不能保证跨章节语义、隐含要求、所有矛盾及扫描字符零漏检。证照线索不证明主体、真伪、有效期或全部资格满足，联网也不能替代事实复核。以招标原件、有效澄清和人工确认的依据作决策。

Windows 为原有主要桌面目标，macOS 提供兼容构建；本候选不据此声称已完成 Windows、Mac Intel 或 Apple 芯片安装包验收。安装包的签名、公证和目标设备运行另行记录。
